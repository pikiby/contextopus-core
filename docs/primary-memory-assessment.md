# Проверка изменений: память основного агента

> Примечание: личные пути и идентификаторы трасс/материалов обезличены; результаты измерений сохранены.

Дата: 2026-09-16. Отчёт фиксирует проверку реализации для версии 0.7.0 до её публикации и установки. Результаты ниже относятся к этому этапу проверки.

## Принятые границы

По прямому указанию пользователя сейчас реализован **запрет на уровне поручения**. Это не техническая изоляция инструментов или файловой системы и не гарантия исполнения инструкций моделью.

Основной агент читает и изменяет PCW: knowledge, Current, ссылки, уплотнение, служебный учёт и разрешённую историю памяти. Исполнитель получает самостоятельное поручение с необходимыми фактами и разрешёнными источниками. В передаваемый текст не включаются координаты памяти, ID материалов, журнал или инструкции управления PCW. Запуск выполняется без наследования диалога основного агента; общие инструкции и инструменты самой среды этим не отключаются.

Сформированный MCP текст явно запрещает исполнителю использовать инструменты PCW, искать, читать или менять `.pcw` через файлы, shell и скрипты. Протокол больше не требует `pcw_assignment_get` от исполнителя. Основной агент передаёт только `handoff.launch_message` и сам привязывает фактическую сессию.

## Что изменено

- Содержательный исходный возврат сохраняет основной агент без переписывания. MCP создаёт filename-ID, записывает UTC `saved_at` и фактический `executor_session_id`. Новое содержательное поручение, включая продолжение, получает отдельный ID.
- Конфликт фактического и сохранённого возврата блокирует принятие до разрешения. Идентичная повторная доставка остаётся идемпотентной.
- Помощник смысловых границ получает текст с позициями и возвращает только окончания блоков. Основной агент вызывает `pcw_submit_boundaries`; MCP проверяет ревизию, порядок и полное покрытие, восстанавливает части из исходного текста и индексирует их. Возврат помощника не создаёт материал knowledge.
- Технические сведения о подготовке и ошибки помощника учитываются в служебном состоянии. Убрана необходимость индексировать отчёты об индексации самих себя.
- Current обновляет основной агент. Цель, ограничения и условие завершения берутся из зарегистрированной задачи; явное исправление задачи использует ревизию и сохраняет незавершённые поручения.
- План промежуточных и финальных фактических проверок, наступившие проверки и нерешённые расхождения сохраняются между вызовами. Проверяющий не назначается автоматически на каждый возврат.
- Отсутствие разрешения на checkpoint обозначается `not_authorized`. Политики `required` и `forbidden` требуют основания. Завершение проверяет фактически требуемые обязательства.

Обновлены [регламент skill](../plugins/persistent-context-workspace/skills/pcw/SKILL.md), его справочные инструкции, [план](../PLAN.md), README и локальный руководящий документ `.pcw/project-update/knowledge/plugin-update-design.md`. Требование сохранять происхождение после уплотнения не вводилось. Прежние отчёты помечены как исторические.

## Автоматические проверки

Последний полный запуск: **147 passed, 6 skipped, 73 subtests passed**, 18.37 секунды. Семь предупреждений относятся к устаревающим API LanceDB. Вывод: `/tmp/pcw-final-tests.log`.

Проверены сохранность исходного текста, включая CRLF, IDs и метаданные, конфликты возвратов, отдельные продолжения, служебные ошибки, неверные и устаревшие границы, согласованность Current, изменение задачи, план проверок, запрет неразрешённого checkpoint и действительная схема MCP. Существующие проверки поиска и восстановления также прошли.

Использовались временные каталоги и тестовые векторы. Шесть opt-in проверок установленной среды, Qwen и расширенных нативных сценариев пропущены. Полная проверка установленного плагина и загрузка Qwen в этот результат не входят. LanceDB-проверки выполнены вне песочницы с ограничением времени: внутри песочницы его фоновое подключение зависало.

Валидаторы skill и структуры плагина прошли. `git diff --check` прошёл.

## Реальный нативный цикл с MCP

Драйвер: [native_primary_memory_probe.py](../tests/native_primary_memory_probe.py). Реальный stdio MCP запускает код текущего checkout с тестовым провайдером векторов. Использованы синтетические сведения о `demo-stage`, а не живой кластер.

| Этап | Исполнитель и наблюдение |
| --- | --- |
| Описание | Нативная сессия `trace-redacted-04`, Luna low, отдельный контекст. Возвращён содержательный Markdown о назначении кластера и трёх ролях Pods. |
| Сохранение | Основной агент сохранил точный возврат через MCP, прочитал его и сопоставил с переданными фактами. ID материала: `00000000000000000000000000000003.md`; `saved_at`: `2026-09-16T20:40:08.328521Z`; сессия автора сохранена в метаданных. |
| Смысловые границы | Нативная сессия `trace-redacted-05`, Luna low, отдельный контекст. На семь исходных единиц возвращён массив `[3,7]`. В трассе помощника нет вызовов инструментов. |
| Применение и завершение | Основной агент передал границы MCP, обновил Current и проверил состояние. `finish.ready=true`, один материал knowledge, `index_status=indexed`, `pending_count=0`. Технических материалов и checkpoint нет. |

**Обнаруженное ограничение:** автор описания вопреки дополнительному условию теста «не использовать инструменты» сделал один лишний вызов `exec`, содержавший только `text(...)` для сообщения о ходе работы. Вызов не обращался к PCW, файлам или вложенным инструментам. Поэтому этот запуск подтверждает содержательный результат и отсутствие обращений к памяти в наблюдаемой трассе, но не полное соблюдение автором запрета на любые инструменты. Помощник границ выполнил своё узкое поручение без инструментов. Это ограничение не скрывается успешным результатом автоматических тестов.

Артефакты цикла находятся в `/tmp/pcw-primary-native-20260916`: `start-mcp.json`, `accept-mcp.json`, `finish-mcp.json`, `author-return.md`, `boundaries.json`, `boundary-evidence.json`. Трассы нативных сессий находятся в `/home/example/.codex/sessions/2026/09/16/` под указанными ID. Тело переданного поручения в нативной трассе зашифровано; повторная побайтовая проверка доставки по открытому тексту этой трассы недоступна. Сформированные поручения сохранены в ответах MCP.

## Предел результата

Проверена локальная реализация и описанный ограниченный нативный цикл. Рабочая память пользователя не мигрировалась и не очищалась; существующие технические материалы не удалялись. Описанный проверочный цикл не включал публикацию в origin и установку выпуска. Проверка не доказывает техническую невозможность доступа субагента к памяти или одинаковое поведение всех поддерживаемых сред.
