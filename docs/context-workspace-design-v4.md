# PCW: общие базы и отдельные контексты

## Принятая цель

Один явно выбранный корень `work_root` содержит `.pcw/<workspace>/` с отдельными INSTRUCTIONS, PROJECT, knowledge, current и tmp. Общий индекс находится в `.pcw/.rag/`, журнал — в `.pcw/.analytics/`. `work_root` обозначает корень памяти, а не автоматически текущий репозиторий. Отдельные корни не объединяются по догадке; перенос из прежних мест должен иметь явные исходные и конечные координаты.

Категория — принадлежность материала контексту. `search(categories=[...])` ищет в указанных контекстах, по умолчанию только в выбранном; `all_categories=true` расширяет область на всю базу. Фильтр применяется до top-N. Ответ возвращает происхождение. Расширение поиска не меняет INSTRUCTIONS, цикл или адрес записи. Общая база использует один согласованный профиль эмбеддингов; несовместимые прежние векторы пересчитываются при миграции.

## Карточки

Формат 2 хранит постоянный `id` в YAML; имя файла отражает заголовок и изменяется независимо. Старые filename-ID сохраняются буквальными значениями `id`. Ссылки адресуют ID, не путь. Индекс хранит workspace, ID, путь и координаты фрагмента. Дубликаты ID блокируют неоднозначное чтение и запись. Изменение только пути/метаданных не требует новых эмбеддингов тела.

Файлы остаются первичным источником; общая база производная. Межконтекстные ссылки разрешены. Чтение их целей не меняет правила задачи. Запись адресуется выбранному контексту; удаление с входящими ссылками из другого контекста требует сначала согласованно исправить эти ссылки, а не незаметно изменить чужие файлы.

## Источники

В теле материала допускается YAML-блок `sources` со списком `reference` и `instruction`. Ссылка может обозначать файл, запись агента, материал, фрагмент, URL, API, запрос или иной однозначно адресуемый объект. Закрытого перечня типов нет. При каждом получении материала агент заново выполняет указанное получение сведений разрешёнными инструментами и извлекает только нужный ответ с условиями. Неоднозначность уточняется; недоступность явно отмечается. Это процедура агента, не автономное исполнение произвольных команд сервером.

Выбор создания обязательных источников остаётся в INSTRUCTIONS; существующие блоки обязательны независимо от этой настройки. Обычные цитаты и навигационные links не становятся обязательными источниками. Старые `required_sources/url/extract` преобразуются в `sources/reference/instruction` без изменения вопроса проверки.

## Обновление

При обнаружении несовместимости агент сразу вызывает pcw-upgrade и возвращается к исходной задаче после успеха. Дополнительное поручение на техническую миграцию не требуется. Инструменты возвращают диагностируемое требование обновления; чтение само не переписывает файлы скрытым образом.

Миграция связывается с ревизией файлов и служебного состояния, сохраняет восстановимый снимок и конечные преобразования. Повтор допускает только проверенные состояния «до»/«после», не произвольные изменения между ними. ID, содержимое, связи, пользовательские инструкции и незавершённые задачи сохраняются. Прежние предложения не получают нового пользовательского одобрения от имени миграции. Общий индекс проверяется по реальным файлам; формат считается обновлённым после завершения файловой части и индексации. Сбой сохраняет состояние для продолжения.

## Проверка

Проверяются создание нескольких контекстов с единым индексом; предфильтрация категорий; чтение и ссылки через границы контекстов; изоляция правил и записи; ID в YAML, переименования, конфликты ID; перевод sources; миграции и повторы после сбоев; сохранность tmp и предложений; согласованность файлов и общей базы. Тесты инструментов не объявляются доказательством универсального соблюдения скилла моделью.
