# 1.7.0 — Client packages and a shared web library

Per-client packages for Codex, Claude Code, Cursor, Hermes, OpenCode and Crush use a shared installer. Missing selected modules are installed through Core; existing incompatible modules produce an explicit error. Procedures expose operation schemas. Semantic web retrieval supports module metadata filters and eligible object IDs. Full skill names avoid automatic short-name collisions. The TUI is removed; use `contextopus web`.

## Installation and compatibility

Use the assets attached to this release and verify their checksums. Modules in this coordinated release require Core 1.7 or later, below 2. Keep persistent data outside source and plugin folders. Use explicit update/upgrade previews for existing roots; client setup does not silently upgrade existing modules.

## Verification and limits

Deterministic embedding tests validate retrieval contracts, not real-model ranking quality. Packaging is not proof that every native client version was exercised.
