# Contextopus Core 1.6.0

Core 1.6 makes file-backed module records and shared instructions available through
the common child SDK. The optional Agents module uses these facilities for reusable
profiles, teams and delegation rules without becoming part of Core.

- Keep replacement module services alive until their enabled state is committed.
- Shared document scans, revision-protected writes/deletes and reconciliation plans.
- Shared instruction files with exact references and full dependency resolution.
- Child RAG search using Core selection, scope and diagnostics; metadata refresh.
- Read-only web library: `contextopus web`, with text and semantic search and sections
  contributed by enabled modules.

Install Core from its ZIP or wheel, then install Agents from its independent release.
Existing module data and user configuration remain separate from replaceable code.
The existing 1.5.0 full starter remains available; it does not contain this release.

Agents 0.3 excludes session communication, event subscriptions and delivery adapters.
This release does not claim new cross-client model-execution or messaging support.

Validation: Core regression suite and isolated module lifecycle checks; consult CI
for platform-specific results. Native client execution and inference readiness remain
separate from source and packaging checks.
