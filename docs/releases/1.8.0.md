# 1.8.0 — Reliable procedures and context rules

Compared with 1.7.0, Contextopus exposes precise operation constraints and keeps
the storage location out of agent-facing MCP calls. The web Library shows
Workspace contexts, their descriptions and the complete linked instruction files.

## Improvements

- Core operation schemas declare paging and search bounds before handlers run.
- Shared instruction binding and direct-relation helpers support independent modules.
- MCP selects a context by name within its configured storage root. `work_root`
  is removed; old filesystem redirects no longer silently select another root.
- Coordinated installers include Workspace 1.8.0, Agents 0.5.0, Session Search
  0.9.1 and Skill Catalog 0.2.0 as optional modules.

## Install or update

Use the client ZIP for Codex, Claude Code, Cursor, Hermes, OpenCode or Crush;
choose Unix for Linux/macOS or Windows for Windows. The starter ZIP includes the
same selectable modules. Python wheel and source archive are also available.
See the [installation guide](../../distribution/README.md).

Python 3.12+ is required. Workspace 1.8.0 requires Core >=1.8,<2. Preserve the
data root and update Core before Workspace. Existing module data is updated through
the normal module update procedure; client setup does not silently upgrade it.
Refresh procedure/tool definitions after restarting the service. Calls that still
pass `work_root` must use the context name instead. No SQL schema migration is added.

## Verification and limits

The candidate passed selected Core and module regression tests, installed-package
checks, six isolated module configurations, 49 MCP calls and 23 artifact/schema
comparisons. An isolated upgrade of existing data and the local working upgrade
preserved 16,309 authored/settings/control files before recording the result.
Live MCP validation, semantic search and web record reads passed locally.

These are local Linux results. Synthetic embeddings in contract tests do not
measure real-model ranking quality. Native assistant registration/execution is
not established by these checks. Direct relation candidates currently cover
Workspace YAML links; complete body and cross-module link handling remains open.
